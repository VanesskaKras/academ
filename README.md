# Academ Assist (власна копія, без CRM)

Лише веб-сайт: React + Vite, API-функції на Vercel (`api/*`), Firebase (Auth, Firestore, Storage).

## Запуск
1. `npm install`
2. `cp .env.example .env.local` і заповнити (Firebase-конфіг, ключі ШІ).
3. `npm run dev`

## Деплой
Свій репозиторій на GitHub → Import у Vercel → ті самі змінні з `.env.example` у Settings → Environment Variables.
